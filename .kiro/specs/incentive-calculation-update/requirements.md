# 自己購入インセンティブ廃止 - 要件定義

## 概要

現在のインセンティブ計算システムから自己購入によるインセンティブを完全に廃止する。系列下位のユーザーやお客様の購入に対するインセンティブは現在のロジックを維持する。

## 要件

### Requirement 1: 自己購入インセンティブの完全廃止

**User Story:** インセンティブ受給資格者として、自分の購入に対してはインセンティブを一切受け取らないようにしたい。

#### Acceptance Criteria

1. WHEN インセンティブ受給資格者が商品を購入 THEN システムは自己購入に対するインセンティブを0円として計算する
2. WHEN インセンティブ計算を実行 THEN 自己購入分は計算対象から除外される
3. WHEN 売上明細を表示 THEN 自己購入のインセンティブ欄は0円として表示される

### Requirement 2: 系列下位購入インセンティブの維持

**User Story:** インセンティブ受給資格者として、系列下位のユーザーやお客様の購入に対するインセンティブは従来通り受け取りたい。

#### Acceptance Criteria

1. WHEN 直下の無資格者（お客様）が購入 THEN 現在のロジック通りインセンティブを受け取る
2. WHEN 系列下位の有資格者が購入 THEN 現在のロジック通り階層差額インセンティブを受け取る
3. WHEN 間接的な子孫が購入 THEN 現在のロジック通り適切な階層差額を受け取る

### Requirement 3: 管理画面の更新

**User Story:** 管理者として、変更されたインセンティブ計算結果を正確に確認したい。

#### Acceptance Criteria

1. WHEN 支払いインセンティブ一覧を表示 THEN 自己購入分を除いた正確なインセンティブ額が表示される
2. WHEN インセンティブ詳細を表示 THEN 自己購入インセンティブが0円として表示される
3. WHEN 総支払いインセンティブを計算 THEN 自己購入分を除いた合計が表示される

### Requirement 4: ユーザー画面の更新

**User Story:** ユーザーとして、変更されたインセンティブ計算結果を売上明細で確認したい。

#### Acceptance Criteria

1. WHEN 売上明細を表示 THEN 自己購入のインセンティブ欄が0円または適切に表示される
2. WHEN インセンティブ合計を表示 THEN 自己購入分を除いた正確な合計が表示される
3. WHEN インセンティブ詳細を表示 THEN 自己購入と他者購入が明確に区別される

### Requirement 5: 計算メソッドの更新

**User Story:** 開発者として、インセンティブ計算メソッドが新しい仕様に従って動作することを確認したい。

#### Acceptance Criteria

1. WHEN bonus_for_purchase_itemメソッドを呼び出し AND 自己購入の場合 THEN 0を返す
2. WHEN bonus_in_periodメソッドを呼び出し THEN 自己購入分を除いた期間インセンティブを返す
3. WHEN monthly_incentive_with_detailsメソッドを呼び出し THEN 自己購入インセンティブが0として詳細に表示される

## 影響範囲

### 変更が必要なファイル

1. **app/models/user.rb**
   - `bonus_for_purchase_item`メソッド
   - `bonus_in_period`メソッド
   - `monthly_incentive_with_details`メソッド

2. **app/views/sales/index.html.erb**
   - インセンティブ表示ロジック
   - 合計計算ロジック

3. **app/views/incentives/index.html.erb**
   - インセンティブ一覧表示

4. **app/views/incentives/show.html.erb**
   - インセンティブ詳細表示

5. **app/controllers/admin/bonuses_controller.rb**
   - ボーナス計算ロジック

## 期待される結果

### 変更前（現在）
- 鈴木愛美: 290,000円（自己購入144,000円 + 系列下位146,000円）
- 中村結衣: 470,000円（自己購入420,000円 + 系列下位50,000円）
- 林美里: 80,000円（自己購入80,000円 + 系列下位0円）

### 変更後（期待値）
- 鈴木愛美: 146,000円（系列下位のみ）
- 中村結衣: 50,000円（系列下位のみ）
- 林美里: 0円（系列下位なし）

## 注意事項

1. 既存のテストデータとの整合性を確認する
2. 過去のインセンティブ計算結果への影響を考慮する
3. ユーザーへの事前通知が必要な場合がある
4. 計算ロジックの変更により、他の機能への影響がないか確認する
