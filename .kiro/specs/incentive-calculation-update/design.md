# 自己購入インセンティブ廃止 - 設計文書

## 概要

自己購入によるインセンティブを完全に廃止し、系列下位のユーザーやお客様の購入に対するインセンティブのみを計算するように既存システムを修正する。

## アーキテクチャ

### 現在のアーキテクチャ
```
User Model
├── bonus_for_purchase_item() - 個別アイテムのボーナス計算
├── bonus_in_period() - 期間内ボーナス計算
└── monthly_incentive_with_details() - 月次インセンティブ詳細

Controllers
├── Admin::BonusesController - 管理画面ボーナス一覧
├── SalesController - ユーザー売上明細
└── IncentivesController - インセンティブ管理

Views
├── admin/bonuses/index.html.erb - 管理画面一覧
├── sales/index.html.erb - 売上明細
├── incentives/index.html.erb - インセンティブ一覧
└── incentives/show.html.erb - インセンティブ詳細
```

### 変更対象
- **User Model**: インセンティブ計算メソッドの修正
- **Views**: 自己購入インセンティブ表示の調整

## コンポーネントと修正内容

### 1. User Model (app/models/user.rb)

#### 1.1 bonus_for_purchase_item メソッド
**現在の動作:**
```ruby
def bonus_for_purchase_item(purchase_item)
  return 0 unless bonus_eligible?
  
  # 自己購入の場合もインセンティブを計算
  if purchase_item.purchase.user == self
    # 基本価格 - 実際の購入価格
    incentive_unit = base_price - seller_price
    return incentive_unit * quantity
  end
  
  # 系列下位の場合の計算...
end
```

**修正後:**
```ruby
def bonus_for_purchase_item(purchase_item)
  return 0 unless bonus_eligible?
  
  # 自己購入の場合は常に0を返す
  return 0 if purchase_item.purchase.user == self
  
  # 系列下位の場合の計算は既存ロジックを維持
  # ...
end
```

#### 1.2 bonus_in_period メソッド
**現在の動作:**
```ruby
def bonus_in_period(start_date, end_date)
  # (1) 自分の販売に対するボーナス - 削除対象
  # (2) 子孫の販売に対するボーナス - 維持
  # (3) 直下無資格者の販売に対するボーナス - 維持
end
```

**修正後:**
```ruby
def bonus_in_period(start_date, end_date)
  # (1) 自分の販売に対するボーナス - 完全削除
  # (2) 子孫の販売に対するボーナス - 維持
  # (3) 直下無資格者の販売に対するボーナス - 維持
end
```

#### 1.3 monthly_incentive_with_details メソッド
**修正内容:**
- `own_sales` フィールドを常に0に設定
- 詳細情報で自己購入インセンティブが0であることを明示

### 2. Views の修正

#### 2.1 sales/index.html.erb
**修正内容:**
- 自己購入行のインセンティブ表示を0円に固定
- インセンティブ合計計算から自己購入分を除外

#### 2.2 incentives/index.html.erb & show.html.erb
**修正内容:**
- 自己購入インセンティブの表示を0円に調整
- 詳細画面で自己購入と系列下位購入を明確に区別

## データモデル

### 影響を受けるモデル
- **User**: インセンティブ計算メソッドの修正
- **Purchase**: 変更なし（データ構造は維持）
- **PurchaseItem**: 変更なし（データ構造は維持）

### 計算ロジックの変更

#### Before (現在)
```
総インセンティブ = 自己購入インセンティブ + 系列下位インセンティブ
```

#### After (修正後)
```
総インセンティブ = 系列下位インセンティブのみ
自己購入インセンティブ = 0 (常に)
```
